# Heart Disease Prediction Using KNN

A machine learning web application built using Python, Scikit-learn, and Streamlit to predict heart disease risk based on user-provided health information.

## Features
- Interactive web interface using Streamlit
- Heart disease risk prediction using K-Nearest Neighbors (KNN)
- Input preprocessing and feature scaling
- Easy-to-use prediction form

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

## Installation

**1. Clone the repository**
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Run the application**
```bash
streamlit run app.py
```
